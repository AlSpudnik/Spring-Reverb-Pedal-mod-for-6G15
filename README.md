## Driver for a spring reverb in the form of a guitar pedal, or a mod for a tube reverb unit 6G15.
Learn more:
[![Reverb Pedal](https://img.shields.io/badge/Reverb_Pedal-orange.svg )](https://mrspudnik.blogspot.com/2026/02/spring-reverb-pedal-6g15.html)

<img src="https://raw.githubusercontent.com/AlSpudnik/Spring-Reverb-Pedal-mod-for-6G15/main/Low%20Power%20ver/photo/IMG_20250826_105552748_HDR.jpg" width="400" alt="Spring Reverb Unit">

The pedal attachment can be used with the Fender Reverb Unit and all its clones.

 <b>TDA2030</b>

 Струмове керування: Магнітне поле, яке розгойдує пружини, залежить виключно від струму, що протікає через котушку, а не від напруги. Якщо подати на котушку сигнал безпосередньо з виходу стандартного підсилювача напруги (яким є готовий модуль TDA2030), високі частоти сильно заваляться, і реверберація вийде глухою, «бубнячою».
